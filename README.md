专为节奏游戏《**冰与火之舞**》（*A Dance of Fire and Ice*, 简称 ADOFAI）打造的 Unity Mod Manager (UMM) 综合增强模组（完整版）。

本模组致力于全面**补全游戏原生缺失的功能与体验细节**，为玩家和谱师带来更完备的判定反馈、地道多语言本地化、跨平台触屏手感模拟以及高拟人化的演播辅助工具。

---

## 📖 核心功能概览

### 2. 地道多语言本地化与排版补全
原版游戏在日语等部分语言下直接沿用了英语判定词（如 Early / Late），且日文字体在部分分辨率下较为纤细。本模组补全了地道的本土化文本与排版表现：
- **地道日语判定文本**：提供符合日语母语节奏游戏习惯的地道判定文本（早め！ / 遅め！ / 早すぎ！ / 遅すぎ！ 等），完整保留感叹号等标志性语义符号，与中文、韩语及英语体系风格高度统一。
- **中文字体平滑替换**：内置「日语界面下使用中文字体」开关（默认开启），在日语环境下平滑替换为更加饱满清晰的中文字体，大幅提升可读性。

### 3. 多层级判定指示器与视觉反馈 (反馈补全)
原生游戏在严格判定下仅提示是否及格，缺乏更细腻的击打区间反馈。本模组补齐了完整的层级化判定指示体系：
- **标判！与宽判！重测指示**：在严格或标准判定下游玩时，若命中落在及格区间，后台实时根据各判定标准重新计算，精准提示该音符落入「标判！」还是「宽判！」。
- **另类指示器+**：支持符号后缀（`标判！+` / `宽判！！+` 太慢 / `标判！-` / `宽判！！-` 太快）或方向前缀（`L-太快！` / `N-太慢！`），直观呈现击打偏早或偏晚。
- **失误判定区间比对**：在打出「太快！！」或「太慢！！」时，亦可比对是否落入宽松或标准窗口，便于高难关卡复盘。
- **文字边框与轨道染色**：可独立切换浮动文字彩色边框，并在打出标判/宽判时将轨道实时染为灰色或绿色，提供双重视觉反馈。

### 4. 移动端判定模拟与双轨自定义模式
为 PC 玩家补齐跨平台触屏手感体验与个性化判定微调：
- **原生 PC 模式** (*Vanilla PC*)：严格 40ms / 标准 65ms / 宽松 90ms，支持指示器增强与轨道染色。
- **移动端判定模式** (*Mobile*)：90ms / 70ms / 50ms，且倍速试炼绝不随加速缩减，在 PC 上还原手机触屏手感。
- **自定义判定模式** (*Custom*)：支持时间 (ms) 与角度 (°) 双轨驱动，支持滑块自由突破输入、百分比乘算器与 3 组快速配置档案。

### 5. 自动播放+ (Autoplay+) 与拟人化演播辅助
针对谱师验谱、录屏演示与实战辅助需求，模组内置全拟人化按键引擎（受安全免责声明保护）：
- **快捷开关与动态本地化**：支持在局内随时使用 <kbd>Alt</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd> 开启或关闭，状态文本与各语言官方自动播放无缝拼接。
- **生物力学拟人化多指算法**：支持左右手惯用手偏好切换（右手优先 / 左手优先），低速平点段优先单指循迹，高速段平滑调度多指轮指。
- **伪双押智能识别**：自动分析前后轨道时值，遇高密伪双押时智能采用双手双指同时击打，保证判定不掉入非 X 完美。
- **自然高斯微抖动误击量计**：绝对锁定在纯正 X-完美 窗口内，运用高斯抖动与一阶自相关漂移偏差驱动误击量计与 Jipper Timing，告别机械死板，稳定保持 100% X-Score。
- **16 键可视化点选映射 + Jipper 同步**：支持 16 个键位可视化点选绑定，支持一键同步 Jipper 键位布局，原生硬件级扫描码驱动 KeyViewer 与外部按键显示。

## 📦 编译与安装

1. **手动编译**：在项目根目录运行 `powershell -ExecutionPolicy Bypass -File build.ps1`，脚本会自动寻找本地 ADOFAI 安装目录并一键编译部署。
2. **自动化构建**：本项目配备 GitHub Actions CI 工作流，推送即可自动打包直出完整的 Zip 模组包并发布至 GitHub Releases。
3. **安装方式**：将 Release 中的 Zip 包拖入 Unity Mod Manager 界面，或解压到 `[游戏目录]/Mods/ADOFAIPlusPlus/` 即可。
