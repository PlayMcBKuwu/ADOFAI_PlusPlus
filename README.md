# ADOFAI Better Judgment (更好的判定)

[![ADOFAI Version](https://img.shields.io/badge/ADOFAI-r80%2B-blue.svg)](https://store.steampowered.com/app/977950/A_Dance_of_Fire_and_Ice/)

专为节奏游戏《**冰与火之舞**》（*A Dance of Fire and Ice*, 简称 ADOFAI）打造的 Unity Mod Manager (UMM) 综合增强模组。原名 `MobileJudgmentMod`，现已全面升级为 **更好的判定 (Better Judgment)**。

本项目基于对游戏逆向代码的研究（判定数学模型、DLC 数据包读取、移动端与 PC 端底层差异对比），旨在让 PC 玩家能够无缝在 PC 上还原移动端手感，并提供极度自由的自定判定窗口、微观判定指示器与实战研究辅助工具。

## 📖 核心功能概览

### 1. 模组总开关与安全声明 (v1.4.0 重磅)
- **安全免责声明体系**：
  - 模组首界面内置安全警告弹窗：严禁在多人联机游戏中使用本模组！作者不为使用本模组造成的任何后果（如账户封禁、联机断开等）承担任何责任。
  - 用户必须在明确知晓并勾选确认免责声明后，方可解锁开启模组总开关。
  - 顶部常驻显示总开关运行状态，随时支持一键即时关闭模组。

### 2. 三大判定模式随时切换
通过 UMM 控制台（游戏内按 <kbd>Ctrl</kbd> + <kbd>F10</kbd>）随时切换三种核心判定模式：

| 模式 | 及格 (Counted) 下限 | 早晚完美 (Perfect) 下限 | 稍偏完美 (Pure) 下限 | 倍速试炼缩减 | 界面标识 | 难度栏表现 |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **原生 PC 模式**<br>*(Vanilla PC)* | 严格 40ms<br>标准 65ms<br>宽松 90ms | 严格 20ms<br>标准 30ms<br>宽松 40ms | 严格 16.7ms<br>标准 25ms<br>宽松 33.3ms | 随倍速等比例压缩 | 保持原生隐藏 | 正常选择 宽松/标准/严格 |
| **移动端判定模式**<br>*(Mobile)* | **90 ms** | **70 ms** | **50 ms** | **绝不缩减**<br>(还原手机手感) | 左上角常驻<br>「**移动判定**」 | 占位重定向并锁定为「**移动**」<br>(左右切换箭头实时隐藏) |
| **自定义判定模式**<br>*(Custom)* | **自由滑块 / 突破输入**<br>(毫秒 ms 或 角度 °) | **自由滑块 / 突破输入**<br>(毫秒 ms 或 角度 °) | **自由滑块 / 突破输入**<br>(毫秒 ms 或 角度 °) | 可自由勾选<br>是否随倍速压缩 | 左上角常驻<br>「**自定判定**」 | 动态匹配严/标/宽图标，锁定为「**自定义**」<br>(左右切换箭头实时隐藏) |

> [!TIP]
> **实时难度箭头控制**：当处于移动端或自定义判定时，关卡难度栏与编辑器内的左右切换箭头会自动隐藏；一旦切回原生 PC 模式（无论是否开启了强制常驻），箭头同帧毫秒级恢复，彻底告别状态不同步。

### 3. 自定义判定模式深度升级
- **时间模式 (ms) 与 角度模式 (°) 双轨驱动**：
  - **时间模式**：直接定义及格、早晚完美、稍偏完美的绝对毫秒窗口。
  - **角度模式**：直接定义及格、早晚完美、稍偏完美的旋转判定角度（°），模组深入底层 Hook `scrMisc.GetAdjustedAngleBoundaryInDeg` 与 `scrMisc.GetAdjustedTimeBoundaries`，实现纯角度控制判定。
- **突破滑块自由输入**：
  - 每一个参数在滑块旁均配备文本输入框，用户可直接键入任意大于 0 的数值，突破滑块预设范围限制。
- **百分比预设乘法器**：
  - 设有百分比输入框（如 50%、80%、120%），点击「严格 / 标准 / 宽松 / 移动」预设按钮即可一键按百分比快速完成三维判定参数的等比乘算。
- **动态代表难度图标**：
  - 不再一味死板显示宽松小盾牌！模组会根据当前自定义数值的严格程度智能换算对应的代表图标（<= 严格阈值显示严格图标，<= 标准阈值显示标准图标，否则显示宽松图标）。
- **3 组快速档案槽位 (Profile Slots)**：
  - 提供 **Slot 1 / Slot 2 / Slot 3** 快速保存与加载功能，随心保存自己的练习档案、极难档案或魔改手感档案，一键载入无缝切换。
- **智能隐藏「关卡速度过快」提示**：
  - 当通过移动判定、自定判定或「强制启用判定选择」使判定菜单常驻，但关卡实际 BPM 低于 220 时，自动屏蔽系统提示 `status.difficultyAdvice`（“关卡速度较快！也许你会希望使用更为宽容的判定窗口。”），保持画面清爽纯粹。
- **通关判定印章 (Clear Stamp)**：
  - 若在通关尝试中（哪怕只是中途临时切换过一次）使用了移动判定或自定判定，结算详细界面中将醒目标记「`[移动判定通关]`」和/或「`[自定判定通关]`」，确保记录真实严谨。

### 4. PC 模式专属：判定指示器家族 (Hit Indicator & Indicator+)
用于评估自己当前击打精度的强大分析工具（*仅在原生 PC 模式下生效*）：

- **原生 GetHitMarginInSec 精准测算**：
  - 抛弃固定差值算式，全面对接官方底层判定函数，自动融入当前瞬时 BPM、倍速试炼以及**练习模式音调 (Conductor Pitch / 90% 降速)** 与 `marginScale`，即使在变速与练习模式下也绝不误判！
- **判定指示器 (Hit Indicator)**：
  - 当打出及格评价（Counted，即太快！/ 太慢！）时，底层使用当帧真实的打击时间差与谱面 BPM 动态梯级测算：
    - ⚪ **标判成立** (<= 标准判定下限)：浮动文字与判定条打点施加**灰色描边**。
    - 🟢 **宽判成立** (<= 宽松判定下限)：仅宽判及格，施加**绿色描边**（提示宽判保命）。
  - **判定条误差量计同步**：判定条打点（`ErrorMeterTick`）同步染上灰/绿描边，直观可视。
- **判定指示器+ (Hit Indicator+)**：
  - 将判定文字替换为更加直观的「**标判！**」与「**宽判！**」。
- **另类判定指示器+ (Alternative Indicator+)**：
  - 为判定指示器追加直观的早晚敲击偏向指示，支持两种工作方式：
    - ➕➖ **正负符号前缀模式 (默认推荐)**：早敲太快显示「**-宽判！**」/「**-标判！**」，晚敲太慢显示「**+宽判！**」/「**+标判！**」（精简模式对应 `-LEN` / `+NOR`）。
    - 🔤 **字符名称前缀模式**：文字显示为「**L太快！** / **L太慢！**」与「**N太快！** / **N太慢！**」（精简模式对应 `LE` / `LL` / `NE` / `NL`）。
- **为「太快！！」与「太慢！！」启用判定指示器 (Double Hit Indicator 适配全补齐)**：
  - 即使在空敲或失误断连的情况下，也重新测算判定窗口；若误差符合条件，全面支持双感叹号失误适配：
    - 符号模式：`--NOR` / `++NOR`、`--LEN` / `++LEN`、`--标判！！` / `++标判！！`、`--宽判！！` / `++宽判！！`。
    - 字符模式：`NTE` (Normal Too Early) / `NTL` (Normal Too Late)、`LTE` (Lenient Too Early) / `LTL` (Lenient Too Late)；中文显示为 `N太快！！` / `L太慢！！`。
    - 毫秒模式：`--60msN!!` / `++80msL!!`。
  - **跨难度保命提示**：在**标判 (Normal)** 难度下游玩失误时，如果该敲击落在宽松窗口内，立即亮起绿色描边并显示 `+宽判！！` / `++LEN` / `LTE`，向玩家明确告知：「**如果换成宽判，这一下本已及格保命！**」
- **结算详细结果 (Detailed Results) 条件呈现**：
  - 开启游戏内「显示详细结果」时，太快/太慢保持原版总 Counted 计数；**仅当本局确实打出了标判或宽判时**（数量大于 0），下方才会展示专属彩色统计行：
    `<color=#aaaaaa>标判: X</color>     <color=#26ff59>宽判: Y</color>`。

### 5. 杂项功能 (Miscellaneous)

- **隐藏星球判定圈 (Hide Planet Judgment Ring)**：
  - 一键隐藏围绕旋转星球的虚线轨道判定圈（`scrRing.line`），还原纯净极简的星球视觉。
- **自动播放+ (Autoplay+ —— v1.4.4 全新架构重构)**：
  - **内部零延迟判定（绝不空敲暴毙）**：
    - 彻底抛弃依赖系统键盘消息延迟触发局内击打的脆弱方案，改为由游戏原生 `OttoHoldHit` 内部时间轴零延迟驱动命中，同时在 `States.PlayerControl` 期间屏蔽物理按键与系统回环信号对 `scrPlayer` 的干扰（开局「按任意键开始」与菜单操作完全正常放行）。
  - **闭环拟人目标 X 精准度 (50% ~ 100%)**：
    - 支持 50% ~ 100% 任意目标 X 精准度调节（含 100%、99.5%、98%、95% 快捷按钮）。
    - 基于自相关正态过程 (AR(1)) 模拟真实人类早晚节奏漂移，并通过游戏原生 `scrMisc.GetHitMarginInDeg` + `HitMarginHelper.IsCounted` 进行终极边界安全校验，**数学级保证 100% 落在合法及格窗口内，绝不可能失误或死亡**。
  - **双通道 KeyViewer (KV) 完美点亮**：
    - **局内 0 帧延迟通道**：Harmony Postfix 拦截 `UnityEngine.Input.GetKey` / `GetKeyDown` / `GetKeyUp`，同帧点亮 `CharonKV` 等局内 UMM 模组。
    - **系统硬件扫描码通道**：Win32 `keybd_event` + `MapVirtualKey` 注入真实硬件扫描码 (`VSC`)，完美支持 `JipperResourcePack` (`SkyHook`)、NohBoard 与 OBS 外部键盘显示器（失去窗口焦点时自动释放并停发，绝不污染外部软件）。
  - **拟人双手十指生物力学排键算法**：
    - 将 2×8 16 键划分为 **左手区 (L: 1~4)** 与 **右手区 (R: 5~8)**，并结合前瞻音符间隔 ($\Delta t$) 动态切换五档人类真实手法：
      1. **慢速平点 ($\le 3.8\text{ KPS}$)**：惯用食指（`E` 或 `P`）自然单点，连续数拍后自然换手，乐句停顿（$>300\text{ ms}$）自动归位主食指；
      2. **中速单双交互 ($3.8 \sim 10.5\text{ KPS}$)**：经典左右食指交替（`E <-> P`），中高密度下自然穿插中指（`2` / `=`）分担负荷；
      3. **快速四指内旋轮指 ($10.5 \sim 19\text{ KPS}$)**：`2 -> E -> = -> P` 左中-左食-右中-右食标准四指内旋；
      4. **高速八指顺滑内旋流 ($19 \sim 32\text{ KPS}$)**：左手 `Tab -> 1 -> 2 -> E` 顺滑内滚接右手 `\ -> Bksp -> = -> P` 顺滑内滚，让 `CharonKV` 左右手贴图呈现真实顺滑位移；
      5. **超高速十六键全指波浪 ($> 32\text{ KPS}$)**：双排 16 键全指内旋爆发。
    - **智能识别自动砖与长条 (Hold)**：自动跳过 `auto` 瓦片；遇到长条时真实持续按住对应按键直至长条结束并在末尾自然松开，绝不在长条尾多敲幽灵键。
  - **2×8 (16 键) 交互式点选绑键面板 + JipperResourcePack 一键同步**：
    - 提供直观的 2 行 × 8 列共 16 个交互式槽位按钮：左键点击按钮后直接按键盘任意键即可完成绑定，右键点击清空槽位，按 <kbd>Esc</kbd> 取消；
    - 内置「**恢复预设 16 键**」与「**从 JipperResourcePack 一键同步键位**」按钮，自动识别 `JipperResourcePack` 当前所用的 `Key4 / Key8 / Key10 / Key12 / Key16 / Key20` 布局并按手部视觉顺序同步。

### 7. 全局高级辅助功能
- **不死模式 (No Fail)** —— <kbd>Alt</kbd> + <kbd>N</kbd>
